# Italian Flat v4 material sources

These project-owned base-color sources are inputs to
`assets-pipeline/scripts/render_italian_flat_property_layers.py`.

## Generated source prompts

### Natural European oak

Square, seamless PBR base-color source; quarter-sawn natural European oak;
subtle grain and restrained knots; long staggered planks; straight-on,
edge-to-edge architectural material scan; neutral diffuse lighting; no baked
shadows, highlights, text, logos, borders, perspective or vignette.

### Light Italian travertine

Square, seamless PBR base-color source; honed ivory travertine with restrained
linear mineral pores and tiny natural cavities; continuous stone without grout;
straight-on, neutral diffuse lighting; no baked shadows, highlights, text,
logos, borders, perspective or vignette.

The Blender script derives restrained bump from base-color luminance and sets
material-specific roughness. Production catalogues should replace these demo
maps with supplier-calibrated PBR scans when exact product matching is required.
